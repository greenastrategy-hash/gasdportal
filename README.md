# 🍄 GASD Portal

Web Portal ศูนย์รวมลิงก์ระบบงานราชการและแอปพลิเคชัน รองรับการแสดงผลแบบ Split View, Dark Mode, และการค้นหาแบบตอบสนองรวดเร็ว

## 🚀 การ Deploy ผ่าน GitHub Pages

1. นำไฟล์ทั้งหมด Push ขึ้นสู่ GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. ที่หัวข้อ **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` (หรือ `master`) / Folder: `/ (root)`
4. กด **Save** และรอระบบทำการ Deploy URL ให้อัตโนมัติ
